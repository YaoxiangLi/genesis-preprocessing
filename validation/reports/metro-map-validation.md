# Genesis metro maps

Three original editable SVGs are generated by `repo/docs/diagrams/render_metro.py`: the implemented DAP-seq graph, an animated version with identical geometry, and a separate architecture roadmap. README embeds the animated map and links its static fallback and source. The nf-core RNA-seq metro map is a visual inspiration, not copied artwork or a claim of nf-core implementation.

Validation: XML parsing, unique IDs, accessible titles/descriptions, exact coverage of the 12 imported workflow processes, static/animated geometry equality, and deterministic regeneration all PASS. Evidence: `results/metro-maps/structural-checks.json`. Native Firefox 157.0.1 browser probes PASS: dash offset changes over 1.1 seconds in normal mode and remains stationary/hidden with reduced-motion preference. See `browser-checks.json`, light/dark screenshots and `results/incremental-prs/metro-browser/` for complete commands/time/logs.

The current map distinguishes full-read alignment from SPP's internal first-50-bp alignment. FastQC observes original reads in parallel. MultiQC receives FastQC, samtools and metadata, not a fictitious SPP parser. Reference provenance and control association are visible. Planned ATAC/scATAC/multiome stages are explicitly separated from implemented DAP-seq.

The SVGs use native text, paths and CSS, no JavaScript, external fonts, raster images or remote resources. Dark mode, print and reduced-motion styles are present; the static SVG is suitable for viewers that disable animation. Browser rendering was inspected; GitHub's remote rendering was not tested because this documentation has not been published. Full pipeline checks are unnecessary for this documentation-only change; the combined pipeline checks already passed independently.

The final architecture map was regenerated after the bulk prototype/contracts passed; labels now distinguish experimental PE ATAC, tested schemas/contracts and planned production scATAC. Final light-mode screenshot: results/metro-maps/architecture-final.png. The implemented DAP map geometry and animated/static hashes remain unchanged.
