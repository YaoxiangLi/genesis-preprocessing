# Implementation checkpoints

- [x] Audit checkout, instructions, public commands and current contracts.
- [x] Record shared specification, compatibility boundary and planning baseline.
- [x] Establish pinned development environment and record baseline fast checks.
- [x] Implement shipped contracts, adapters, bounded validators and CLI.
- [x] Implement registry migrations, imports, search, export, backup and restore.
- [x] Implement declarative QC, immutable review and reviewed catalog export.
- [x] Add read-only review summaries and safe report downloads.
- [x] Exercise offline acceptance, regressions, installed packaging and scale fixture.
- [x] Publish usage, exact validation evidence, limitations and rollback guidance.

Each implementation checkpoint has focused checks before integration. No automatic
commit or push is part of these checkpoints. See IMPLEMENTATION_BRIEF.md for scope.

Evidence: [validation report](../../validation/reports/curation-foundations-validation.md).
Live scientific containers, SSH/schedulers and AI/GPU acceptance are explicitly
NOT RUN or out of scope; completed local checkpoints do not imply those passed.
